A one-line sign for the door of a haunted server room, built for make.fun's "Funniest Sign on a Haunted Server Room Door" bounty.

## Run it

```sh
python3 main.py
```

Writes the sign to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
